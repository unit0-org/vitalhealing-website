# Vital Healing website

Bilingual (ES/EN) static marketing site for Dianeris Posada's coaching brand, built with Astro.

**Before changing any page or copy, read and follow `CONTENT_RULES.md`.** It holds the voice (third person for Dianeris, "you" for the reader, short and direct), the bilingual rules, and the design-system rules (tokens, one orange CTA marker per section, no stock people).

- Copy: `src/i18n/es.ts` (source) and `src/i18n/en.ts`. Never hard-code text in components.
- Settings (links, masterclass date, form endpoint): `src/config.ts`.
- Commands: `npm run dev`, `npm run build`, `npx astro check`.
